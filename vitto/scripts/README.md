# Scripts de análise

- `analyze.py` lê o CSV original (mantido fora do site) e atualiza `dados.json`.
- `office.py` cria o relatório DOCX, a apresentação PPTX, os gráficos e o CSV de previsão.
- `finalize.py` ajusta a apresentação e o título do relatório.
- `export_slides.py` converte a apresentação para PDF.

Instale `requirements.txt` antes de executar. Gere os arquivos a partir da pasta `vitto/` com Python 3.
